# Проект: Аналитика книжного магазина

## Цель
Демонстрация навыков работы с реляционными данными и базовой аналитики на Python + SQL.

## Структура данных
* `authors` — авторы;
* `books` — книги (связь с авторами);
* `orders` — заказы (связь с книгами).

## Выполненные задачи
1. Создание схемы БД с связями.
2. Заполнение тестовыми данными.
3. Анализ продаж по жанрам (SQL‑запрос с JOIN и агрегацией).
4. Экспорт отчёта в CSV.

## Как запустить
1. Установите зависимости: `pip install sqlalchemy`.
2. Запустите `python database_extended.py`.
3. Запустите `python analytics_demo.py`.
4. Откройте файл `sales_report.csv` для просмотра результатов.

## Выводы
Проект показывает:
* понимание нормализации данных (отдельные таблицы для авторов и книг);
* умение писать аналитические запросы (группировка, сумма);
* навык экспорта данных для дальнейшей работы (CSV);
* базовый workflow аналитика: данные → запрос → отчёт.
